# Minimum

Live toggle optimization mod for Geometry Dash 2.2081 + latest Geode.

Sequel to [Algebra Dash](https://github.com/cgytrus/AlgebraDash).

## Live toggles

Open Geode, open Minimum settings, flip Enable Minimum or any option in a level. No restart. Compare FPS with and without the mod instantly.

## Features

Enable Minimum master switch  
Performance Mode  
Skip empty batches  
Cull and stop offscreen particles  
Hard particle cap (default 48)  
Reduce particle emission  
Skip offscreen particle draw  
Fast alt tab  
Optional RGBA8888 / MSAA

## Dense levels

Keep Performance Mode on. Lower Particle Cap to 40 or less if lag spikes remain. Keep Reduce Particle Emission on.

## Recording / Discord

Performance Mode on. Particle Cap low. AA at 0. Use Game Capture.

## Build

GitHub Actions builds Windows and macOS `.geode` on every push to main.
