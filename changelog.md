# v3.2.1

- Fixed: half the source files were missing from the repo, so the mod never actually built. Everything is back and builds clean.
- New: Low Latency Mode now works on Android and iOS too, not just desktop.
- New: Unlock FPS on Android / iOS. On a 90/120 Hz screen the game can finally go past 60. Off by default, set the limit to your screen.
- New: reworked pause menu popup. One row per toggle (much easier to hit on a phone), a live FPS readout up top, and a GitHub button.
- Fixed: the quick toggles in the popup could show the wrong state after you flipped them.
- Fixed: toggling a switch twice fast no longer fights itself, the switch always matches the saved setting.
